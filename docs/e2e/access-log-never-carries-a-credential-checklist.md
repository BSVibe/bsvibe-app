# E2E — 액세스 로그가 크리덴셜을 안 적는다 (#1027)

**대상 PR**: `uvicorn.access` 에 **모든 쿼리 파라미터 값**을 리댁션하는 필터
**전제**: prod 는 autodeploy. 배포 후 **컨테이너 재생성**으로 확인.

> 🧭 **파라미터 이름 목록으로 하지 않았다.** 그건 내 상상력만 증명한다
> ([[absence-guard-listing-spellings-proves-only-imagination]]). **값을 전부 지우고 키는 남긴다** —
> 목록이 필요 없는 완전한 규칙이고, 새 엔드포인트가 쿼리에 크리덴셜을 실어도 **나온 날부터** 덮인다.
